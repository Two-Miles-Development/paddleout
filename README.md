# Paddleout — Surf the Change

Live site: https://paddleout.life · Hosted on Netlify · Edited with Claude Code

## How to update the site

1. Open **claude.ai/code** (or the Code tab in the Claude desktop or phone app). Choose a **Cloud** environment and this repository.
2. Describe the change in Japanese or English, e.g. "Add today's daily article: …".
3. Claude Code makes the change and opens a **pull request**.
4. Netlify adds a **preview link** to the pull request after a minute or two. Check it.
5. If it looks right, click **Merge**. The live site updates within a minute or two.

To add a photo or PDF: open the repository on GitHub → `img` (or `files`) folder → **Add file → Upload files**, then ask Claude Code to use it.

If something goes wrong, any earlier version can be restored from Netlify's **Deploys** page with one click.

Form submissions are emailed by Netlify (Netlify → Forms → Form notifications).

See `CLAUDE.md` for how the site is structured.
